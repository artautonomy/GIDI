# GIDI - a visualiser for MIDI

GIDI is a free web application for MIDI. It uses note on/off messages to create animations on a web browser, no account required. The web app offers:

- Either play live MIDI or import a MIDI file
- Use multiple styles (Piano, Firework, Mirror, Swirl, Cube)
- Full customisation of the scene e.g. change note/expression/background colours, lighting, autorotate, note dampening
- Record camera sequences, transition between shots by either 'Note down' or 'Time interval'
- Map different MIDI statuses (e.g. Pitch Wheel or Sliders) to change the scene in real-time

- Leave feedback on socials (bottom right on GIDI)
- Perform a pull request and collaborate
- Spread the word to fellow musicians using MIDI
- Donate to help fund hosting costs (PayPal, bottom right on GIDI)
